# AirUX agent instructions

Before planning or implementing AirUX work, read the project references in
`for_agent_reference/`:

- `AGENT_CODING_WORKFLOW.md` defines the required development and review gates.
- `AirUX Design Document.md` defines the product, architecture, contracts, and
  milestones.
- `AGENTS.md` contains the project's general coding guidelines.
- `airux_architecture.png` is the architecture diagram; inspect it when the task
  involves system boundaries or integrations.

Treat the design document as the source of truth for current scope. If a task
requires changing a major design decision, follow the explicit decision gate in
the coding workflow before implementation.
