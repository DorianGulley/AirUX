# AirUX

AirUX lets a coding agent record focused evidence from a localhost web app,
submit that recording for private human review, and continue from the reviewer's
decision.

See the [AirUX Review onboarding guide](skills/airux-review/README.md) to connect
Codex or Claude Code and create your first Review.

Production deployment and service configuration are documented in
[DEPLOYMENT.md](DEPLOYMENT.md).
